# TaskTracker – MERN Stack Application

A full-stack Task Management application built using the **MERN stack** (MongoDB, Express.js, React.js, Node.js).

Users can register, log in, and manage their personal tasks with features like priority, status tracking, and due dates.

---

## Key Features

- User Authentication (Register / Login) using JWT
- Create, Read, Update, and Delete (CRUD) tasks
- Task Priority (Low, Medium, High)
- Task Status (Pending, In Progress, Completed)
- Filter tasks by status and priority
- Protected routes (only logged-in users can access tasks)
- Responsive and clean UI

---

## Technologies Used

**Frontend:**
- React.js
- React Router
- Axios
- Vite

**Backend:**
- Node.js
- Express.js
- MongoDB + Mongoose
- JWT (JSON Web Token)
- bcryptjs
- express-validator
